- Où : `docs/adr/0048*.md:39` ; `data/titles/halo_infinite/reference/map_backgrounds/*.plan.webp` (111 fichiers,

  amender, pas l'image à retirer.
- Décision : traité, plan suites-audit, item D.1 (accord du user sur D-1, 2026-11-16) : ADR 0048 amendé (D-3, D-7, « État courant »), ligne 0048 de `CLAUDE.md` corrigée ; l'image plan est conservée.
