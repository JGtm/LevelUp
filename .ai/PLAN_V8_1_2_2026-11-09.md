## 1. Contrat d'exécution

Le skill `plan-execution` s'applique en entier. Ce qui est propre à ce plan :

- **Rôles.** Le pilote (session principale) ne code pas : il brieffe, relit chaque compte rendu sur pièces, commite, ouvre et fusionne les PR, tient ce plan et `.ai/thought_log.md`. Les exécutants ne touchent ni au plan ni au journal, n'écrivent jamais de prompt pour la suite, et remontent tout STOP.
- **Modèle.** Celui de la table, passé explicitement. Haiku : remplacements mécaniques dont le résultat se contrôle par test ou grep. Sonnet par défaut. Opus : items marqués, justifiés.
- **Branches.** Intégration : `release/v8.1.2`. Cinq voies indépendantes, chacune son worktree : `git worktree add ../LevelUp-wt-812-<voie> -b feat/812-<voie> release/v8.1.2`, voies `web` (étape 1), `stats` (2), `bureau` (3), `film` (4), `licences` (5). Préfixe `feat/` obligatoire : `wt/*` n'a pas de CI. Les voies peuvent courir en parallèle ; à l'intérieur d'une voie, ordre strict. L'étape 6 commence quand les cinq voies sont fusionnées et que 5.9 est clos, car elle réécrit les imports de ~580 fichiers et gèle `libs/`.
- **Fusion.** PR de voie vers `release/v8.1.2`, squash par le pilote une fois la CI de la PR verte, le check lu nommément, pas l'absence d'échec. Le go du user sur ce plan couvre les commits sur les branches de travail et ces fusions. Le `main` de LevelUp reste un geste du user.
- **Gate d'une étape.** Commandes exactes de l'item, code de sortie lu, jamais la seule sortie filtrée. Typecheck avec cache purgé (`npx tsc -b --force`). Avant toute clôture d'item Go : `go vet` du paquet et `make go-api-lint`.
- **Caches.** `GOCACHE=%LOCALAPPDATA%\go-build-812-<voie>`, `GOLANGCI_LINT_CACHE=%LOCALAPPDATA%\golangci-812-<voie>` ; à la clôture de la voie `powershell -File scripts/disk-hygiene.ps1 -Lot 812-<voie> -Apply`. CGO sous PowerShell : `C:\msys64\ucrt64\bin` en tête du PATH, `CGO_ENABLED=1`.
- **Interdits.** `git stash`, `git add -A`, tout push sur le `main` de LevelUp, navigateur et code d'appareil, toute cuisson ou balayage du parc hors D-16, `git push --force`. Aucune citation de `.ai/` dans un commentaire de code. Pas d'emoji versionné.
- **Périmètre figé (user, 2026-11-09).** Rien de nouveau n'entre dans la 8.1.2. Ce qui apparaît pendant l'exécution se note à la section 7, par le pilote, n'est pas traité, et passe dans `.ai/BACKLOG.md` à 7.3, sauf si cela bloque le gate de l'item en cours.
- **Reprise.** Lire ce contrat, le journal (section 8), reprendre à la première case non statuée de chaque voie.
- **Bases de données.** Le serveur local peut être l'application installée, données sous `%LOCALAPPDATA%\LevelUp` : vérifier ce qui tient un fichier avant toute lecture sous `data/`.
