## Couche UI — Streamlit Moderne

### Navigation (`st.navigation`)

L'application utilise `st.navigation` pour le chargement paresseux des pages :

```python
# streamlit_app.py — Schéma simplifié
from src.app.page_router import build_navigation

def make_overview_page():
    """Closure paresseuse : overview n'est importé qu'à l'appel."""
    from src.ui.pages.overview import render_overview_page
    render_overview_page(state)

# 11 closures similaires pour chaque page
default_page, all_pages = build_navigation(pages_dict)
page = st.navigation(all_pages, position="hidden")
page.run()
```

**Fichiers clés** :
- `streamlit_app.py` — 11 page closures + `st.navigation`
- `src/app/page_router.py` — `build_navigation()`, `_PAGE_URL_PATHS`, `_PAGE_ICONS`
- Fallback legacy : `dispatch_page()` pour Streamlit < 1.36

### Fragments (`@st.fragment`)

Les sections interactives sont décorées avec `@fragment_if_available` :

```python
from src.ui.streamlit_modern import fragment_if_available

@fragment_if_available
def render_kda_trends(df: pl.DataFrame) -> None:
    """Ce fragment se re-render indépendamment de la page."""
    fig = create_kda_chart(df)
    plotly_chart(fig, config=PLOTLY_CLEAN_CONFIG)
```

**26 décorateurs** sur 8 pages : timeseries, session_compare, win_loss, objective_analysis,
career, match_view_charts, match_view_participation, match_view_players,
teammates_charts, session_compare_charts.

## Couche Données — DuckDB Centralisé

### Context Manager `duckdb_read_only`

Toute lecture DB hors `DuckDBRepository` passe par le context manager :

```python
from src.utils.db import duckdb_read_only

with duckdb_read_only(db_path) as conn:
    result = conn.execute("SELECT * FROM career_progression").pl()
```

### Vue Matérialisée `mv_player_matches`

Pré-calcul des jointures fréquentes :

```sql
CREATE TABLE mv_player_matches AS
SELECT mp.*, mr.start_time, mr.map_id, mr.playlist_id, mr.game_variant_id,
       meta_map.name AS map_name, meta_pl.name AS playlist_name
FROM shared.match_participants mp
JOIN shared.match_registry mr ON mp.match_id = mr.match_id
LEFT JOIN meta.maps meta_map ON mr.map_id = meta_map.asset_id
LEFT JOIN meta.playlists meta_pl ON mr.playlist_id = meta_pl.asset_id
WHERE mp.xuid = ?
```

### Pré-calcul Post-Sync

`scripts/post_sync_compute.py` crée 3 tables après chaque sync :

| Table | Contenu |
|-------|---------|
| `precomputed_sessions` | Sessions calculées (gaps, labels) |
| `precomputed_kda_trend` | Tendance KDA glissante |
| `precomputed_global_stats` | Agrégats globaux (wins, kills, etc.) |

## Couche Filtres — Callbacks Natifs

Les filtres utilisent des callbacks `on_click`/`on_change` au lieu de `st.rerun()` :

```python
# Avant (v5.0) — Double rerun
if st.button("Tout sélectionner"):
    st.session_state[key] = all_values
    st.rerun()  # Rerun explicite

# Après (v5.1) — Callback natif
def _select_all():
    st.session_state[key] = all_values

st.button("Tout sélectionner", on_click=_select_all)
```

**14 `st.rerun()` restants** dans `src/` — tous légitimes (navigation inter-pages, changement de profil).

## Conventions — Règles v5.1

1. **Tout `st.plotly_chart`** doit inclure `config=` (STATIC ou CLEAN)
2. **Préférer `@st.fragment`** pour les sections interactives multi-charts
3. **Utiliser `duckdb_read_only()`** pour les lectures hors Repository
4. **Utiliser `on_click`/`on_change`** au lieu de `st.rerun()` pour les filtres
5. **Échapper les données** dans les composants `unsafe_allow_html`
6. **Pandas interdit** — Polars uniquement, conversion `.to_pandas()` à la frontière Streamlit/Plotly
7. **SQLite interdit** — DuckDB uniquement
8. **`width="stretch"`** au lieu de `use_container_width=True` (déprécié)
